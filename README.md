# Brain Tumor Classification Web App

This is a Streamlit-based web application that classifies brain MRI scans into four categories:
- Glioma Tumor
- No Tumor
- Meningioma Tumor
- Pituitary Tumor

## Dataset
The model was trained on the Brain Tumor Classification MRI dataset.

## How to Run locally:
1. Install dependencies:
   ```bash
   pip install streamlit tensorflow opencv-python Pillow numpy
   ```
2. Run the application:
   ```bash
   streamlit run app.py
   ```
